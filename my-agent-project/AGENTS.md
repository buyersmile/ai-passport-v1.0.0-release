# MASTER AGENT SYSTEM INSTRUCTIONS (MOBILE)

## 1. SKILL & TOOL REGISTRY
- สแกนโฟลเดอร์ `.ai-skills/` เพื่อดึงสกิลที่เกี่ยวข้องก่อนเริ่มงานเสมอ

## 2. STRICT ENGINEERING WORKFLOW
- ห้ามเขียนโค้ดทันที! ต้องทำตาม 5 ขั้นตอน:
  1. Understand Requirement (ทำความเข้าใจโจทย์)
  2. Spec & Architecture (วางสเปก)
  3. Implementation Plan (วางแผนย่อย)
  4. Write Tests (ออกแบบการทดสอบ)
  5. Execute & Code (ลงมือเขียนโค้ด)

## 3. PERSISTENT MEMORY LAYER
- อ่าน `.ai-memory/context-history.md` ก่อนเริ่มเซสชันเสมอ
