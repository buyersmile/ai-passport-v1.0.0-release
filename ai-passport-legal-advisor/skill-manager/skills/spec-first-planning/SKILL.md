# Spec-First Planning
1. เริ่มด้วย `mem start "<งาน>"` เพื่อดึงการตัดสินใจและข้อจำกัดเดิม
2. `spec new <slug>` แล้วกรอก: requirement → คำถามค้าง → สเปก → แผน → แผนทดสอบ
3. ถามผู้ใช้เฉพาะสิ่งที่ขาดจริง (ไม่เกิน 3 ข้อ) แล้วบันทึกคำตอบลงสเปก
4. `spec check <slug>` ต้องผ่าน แล้วให้ผู้ใช้อนุมัติด้วย `spec approve <slug>`
5. ก่อนเขียนโค้ดต้องผ่าน `spec gate <slug>` (ถ้าสเปกถูกแก้หลังอนุมัติ ด่านจะปิดและต้องอนุมัติใหม่)
6. ทำตามแผนทีละข้อ ติ๊กด้วย `spec tick <slug> <n>` และบันทึกการตัดสินใจด้วย `mem add decision`
งานเล็กมากย่อสเปกเหลือประโยคเดียวได้ แต่ห้ามข้ามการเข้าใจโจทย์
